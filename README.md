# FIT-ALL

App personal de entreno y dieta: rutina editable, registro de series con temporizador de descanso, dieta con calorías y macros, peso, medidas y progreso.

Es una app web instalable (PWA): se abre desde el navegador y se instala en la pantalla de inicio de iPhone y Android. Funciona sin conexión y guarda los datos solo en el móvil (con copia de seguridad en JSON desde Ajustes).

Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
